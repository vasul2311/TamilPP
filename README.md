# TamilPP: Tamil Domain Specific Language (DSL)
A Python-based compiler that allows users to write code using Tamil keywords.

## 🚀 Project Overview
This project was developed for my **final year engineering expo** to bridge the gap between native Tamil speakers and programming. It translates Tamil-based syntax into executable Python code.

## 🛠️ Built With
*   **Python:** Core logic and compiler class.
*   **Translation Mapping:** Custom keywords for Tamil computing.
